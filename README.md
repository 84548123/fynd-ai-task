# Fynd AI Feedback System

A real-time customer feedback analysis tool powered by Google Gemini 2.0.

## Features
- **User Dashboard:** Submit reviews instantly.
- **AI Analysis:** Automatically generates summaries, sentiment ratings, and action items.
- **Admin Dashboard:** View processed insights in a secure interface.
